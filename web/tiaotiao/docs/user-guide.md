# 跳跳使用说明

## 打开网页

在 Windows 上运行项目根目录的 `启动跳跳.bat`，然后使用 Microsoft Edge 打开 `http://127.0.0.1:4173/`。也可以在终端进入项目目录后运行 `node server.mjs`。服务默认只监听本机地址 `127.0.0.1`。

首次使用时，Edge 会询问麦克风权限，请选择允许。语音识别需要联网，并依赖 Edge 支持的 SpeechRecognition；语音合成使用浏览器 Web Speech API，优先选择可用的中文 Microsoft Yunxia 音色，若设备没有该音色则尝试系统提供的中文声音。

## 语音交互

- 待机时说“你好跳跳”，眼睛进入聆听状态。
- 也可以在下方调试台点击“进入聆听”，直接开始接收指令，无需说唤醒词。
- 说完后停顿约 1.5 秒，系统会把识别到的句子提交给对话模型。
- 思考、语音合成和播报阶段会通过表情和调试信息显示进度。
- 音乐播放或天气显示期间说“你好跳跳”，会退出当前界面并进入聆听状态。

如果麦克风没有启动，请在 Edge 地址栏左侧的网站权限中允许麦克风，再刷新网页。持续语音识别在部分网络、系统策略或 Edge 版本下可能不可用；这时请检查浏览器控制台和下方识别状态。

## 天气查询

可以询问“今天天气怎么样”或“今天徐州天气怎么样”。不指定城市时由天气服务按请求来源定位；指定城市时使用所说的城市。天气图标、温度和天气描述会显示在眼睛区域，并由浏览器语音播报。播报结束约 3 秒后自动返回表情页。

## 音乐播放

可以说“我想听起风了”或“我想听某位歌手的歌”。程序搜索匹配结果并获取音频、封面及歌词。调试台也提供手动搜索和平台选择。支持网易云、QQ 音乐、酷我、酷狗、咪咕和千千音乐，实际结果和播放可用性取决于上游接口与音源。语音推荐规则会避开周杰伦歌曲。

播放期间说“你好跳跳”可退出音乐页。页面内的播放按钮控制暂停和继续；停止按钮结束播放并返回表情页。

## 调试台

- **背景颜色**：选择纯黑、荧光绿 `#00ff00` 或自定义颜色，自动即时应用并保存在当前浏览器。
- **进入聆听**：跳过唤醒词，直接等待语音指令。
- **表情预览**：手动播放一次指定表情。
- **模型名称**：修改当前浏览器使用的聊天模型名称。
- **歌曲搜索**：手动搜索并播放歌曲。
- **状态与日志**：查看识别、AI、语音合成、天气和音乐的处理状态。

调试台设置使用浏览器 `localStorage`，仅保存在当前浏览器配置中，不会写入服务器 `.env`。
