# 跳跳网页使用说明

本页面是 Jumper Agent 的浏览器眼睛与语音助手。它可以单独运行；与仓库整合启动器一起运行时，还能
把网页左右屏幕同步到 MuJoCo 模拟器，并接收模拟器返回的动作执行进度。

## 启动网页

安装 Node.js 18 或更新版本，然后在仓库根目录运行：

~~~powershell
.\start-tiaotiao-web-simulator.ps1
~~~

这会启动网页、投屏 GUI、模拟器和 Edge。若只需网页，在 web/tiaotiao 目录执行：

~~~powershell
node server.mjs
~~~

默认页面位于 http://127.0.0.1:4183/。只运行网页时不需要 Python、MuJoCo 或动作包。完整启动要求、
圆屏区域选择和模拟器控制方法见[网页与模拟器开发说明](../../../docs/TIAOTIAO_DEVELOPMENT.zh.md)。

## 语音与唤醒

在支持 Web Speech API 的浏览器中授权麦克风。待机时可以说“你好跳跳”“你好挑挑”或“你好调调”，
也可以使用调试台的“进入聆听”按钮。说完指令后短暂停顿，网页会将识别内容交给已配置的对话服务。
语音识别和语音合成均由浏览器提供；设备、浏览器权限和网络情况会影响可用性。

## 表情、天气和音乐

网页支持待机、聆听、思考、播报及多个手动预览表情。也可以请求天气信息或搜索音乐；具体内容由
已配置服务提供。调试面板支持查看前端状态、设置浏览器内偏好和直接预览表情。

当音乐或天气内容显示时，说唤醒词可以返回眼睛页面。音乐播放是否成功取决于上游搜索结果、音源有效
期、跨域策略和浏览器的自动播放权限。

## 模拟器圆屏

整合启动器会把浏览器画面分别投到机器人模型的两个圆屏。眼睛状态、天气图标、音乐封面和歌词使用
各自的屏幕渲染。若要投送本机任意窗口或桌面内容，在 GUI 中输入圆形直径并选择左右屏区域。

网页同步和桌面截图是两种独立来源，一次只启动一种。没有模拟器时网页仍能使用，但屏幕同步和动作
队列不可用。

## 让机器人执行动作

对话中可以提出支持的行走、舞蹈、手势、跳跃或停止指令。连续动作会进入网页任务列表并依次提交给
本机模拟器动作桥。浏览器里的进度表示请求步骤状态，不是实体机器人的状态，也不代表硬件已执行动作。

## 隐私与设置

公开版本不预设 AI 接口地址或默认模型。要启用聊天，在 web/tiaotiao/.env.example 的副本中自行
设置本机 AI 配置，并保管好密钥。音乐和天气的凭据也只放在本机配置中。浏览器偏好存于当前浏览器的
本地存储，不会替代服务端密钥配置。更多内容见[部署与安全说明](deployment-security.md)。
