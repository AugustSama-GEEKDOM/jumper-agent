# 部署与安全说明

## 本地运行

1. 安装 Node.js 18 或更新版本；使用浏览器语音功能时建议使用 Microsoft Edge。
2. 在 web/tiaotiao/.env.example 旁边创建本机 .env 配置。
3. 在本目录运行 node server.mjs，或使用仓库根目录的 Windows 整合启动器。
4. 默认从 http://127.0.0.1:4183/ 打开网页。

服务只绑定本机回环地址。网页单独运行不启动模拟器；动作桥和双屏投帧只由本机整合模拟器进程提供。
不要把这两个本地接口改为公网监听或用无访问控制的反向代理转发。

## 凭据配置

公开环境模板中的 AI 地址、密钥、默认模型和音乐凭据保持空白。使用者可在本机 .env 文件配置自己的值。
不要把 .env 提交、放入 ZIP、粘贴到 issue、聊天记录、网页前端、截图或浏览器存储。

AI 密钥由 Node 服务端读取，只用于代理请求。浏览器只能访问本机服务路由；不要在 app.js 或 HTML 中
拼接外部 AI 请求。修改本机配置后需要重新启动 Node 服务。

天气服务当前使用不带本机密钥的请求。音乐和天气服务的隐私、可用性、授权、配额及返回内容由相应
服务提供方决定。

## 浏览器权限与服务边界

语音识别和语音合成由浏览器执行，需授予麦克风权限。自动播放可能被浏览器拦截，语音识别也可能
受网络或系统策略影响。成功打开本机页面只能说明静态服务可访问。

显示同步更新 MuJoCo 模型的渲染纹理，不代表真实机器人屏幕收到内容。顺序动作桥只接受本机模拟器
允许的动作，也不是硬件控制服务。不要将模拟器动作接口用于实体机器人。

## 源码压缩包

完整项目源码使用仓库根目录 package-project.ps1 打包。脚本排除 .env、浏览器个人配置、日志、缓存、
检查点和其他 ZIP；分享前检查压缩包列表。只保留空白模板 web/tiaotiao/.env.example。
