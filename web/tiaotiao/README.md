# 跳跳机器人眼睛与网页助手

此目录包含跳跳浏览器界面和仅供本机使用的 Node.js 服务。网页可显示动画眼睛、语音交互、音乐与
天气内容，并在本机模拟器在线时同步圆屏画面和执行有限的顺序动作。完整项目启动方式见仓库根目录
的 [Windows 整合开发指南](../../docs/TIAOTIAO_DEVELOPMENT.zh.md)。

## 本地运行

需要 Node.js 18 或更新版本。服务使用 Node.js 内置模块，无需安装 npm 包。

~~~powershell
Copy-Item .env.example .env
node --check app.js
node --check server.mjs
node server.mjs
~~~

在浏览器打开本机服务地址。只运行网页时，语音识别和播放由浏览器提供，首次使用需授权麦克风。
连接模拟器、配置语音服务和使用屏幕同步的步骤见整合开发指南。

## 本机配置

.env.example 仅列出可选变量名。AI 接口地址、密钥和模型在公开模板中都为空；启用聊天服务时，
只在本机 .env 中填写自己的配置。音乐和天气服务使用独立凭据。不要把 .env 放进版本控制、
截图或公开压缩包。仓库已有 .gitignore 会忽略此文件。

## 目录

| 文件 | 作用 |
|---|---|
| index.html | 眼睛、天气/音乐视图、交互控件与调试面板 |
| style.css | 屏幕布局、表情绘制和动画 |
| app.js | 浏览器状态、语音、媒体、圆屏同步和动作队列 |
| server.mjs | 静态文件服务、外部服务代理和动作数据校验 |
| docs/ | API、部署安全、代码导航、开发和截图说明 |

宣传动画页面与主网页相互独立，不参与 Node 服务运行。
